MiniStory Code Studio

Escribe una idea, genera una minihistoria animada y grábala como vídeo desde el navegador. Esta primera versión usa una historia de demostración y todavía no conecta una IA externa.

Listo. Pulsa “Crear escenas”.

Formato de vista previa: 16:9. La exportación graba la animación en tiempo real; mantén esta pestaña abierta mientras termina.

Qué incluye esta versión

✓ Animación dibujada por código · ✓ Tres escenas · ✓ Texto adaptado a tu idea · ✓ Grabación del lienzo si el navegador lo admite.

Para convertir cualquier idea en dibujos realmente distintos, el siguiente paso es conectar un modelo de IA que escriba una descripción estructurada de cada escena. No pegues claves secretas de API en este archivo público.

Consejo para iPad: abre este archivo desde una web HTTPS para probar la grabación. El navegador decide qué formato puede exportar (MP4 o WebM); si MP4 no está disponible, la aplicación te lo indicará.
